# PROJETO-EXTENSAO-IV

## Proposta de Projeto: Desenvolvimento de um Jogo Desktop de Dedução e Espionagem para UPXP
Visão Geral do Projeto
Trata-se de um software desenvolvido para PC (Computador/Notebook) focado em dedução, comunicação e blefe, projetado para partidas presenciais dinâmicas e interativas em um único terminal dedicado para a UPXP.
## Dinâmica das Rodadas no PC
 ### * Atribuição Secreta de Papéis: Na tela do computador, os jogadores alternam sua vez para visualizar sua função em segredo antes de passar a cadeira/teclado para o próximo participante.
 ### * Jogadores Comuns: Visualizam a palavra-chave da rodada no monitor.
 ### * O Impostor: Recebe apenas uma dica genérica ou categoria associada ao tema.
## Como Funciona o Desafio
 ### * Pistas Sutis: Os jogadores comuns dizem em voz alta pistas curtas sobre a palavra secreta. O desafio é demonstrar aos outros que conhecem o termo, sem ser tão explícito a ponto de revelar a resposta ao impostor.
 ### * O Blefe do Impostor: O impostor observa o comportamento e as falas do grupo no estande para tentar deduzir o termo correto e, na sua vez, fala uma pista vaga para tentar se camuflar.
 ### * Votação e Dedução: Se o impostor der uma pista desconexa ou demonstrar falta de conhecimento sobre o assunto, o grupo deve identificar a contradição e votar na interface do computador para eliminá-lo.
